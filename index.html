Multi-language integration

One request away from live weather

The OpenWeatherMap API uses standard HTTPS query parameters and JSON payloads, working cleanly with your preferred runtime and HTTP client.

  • Environment-variable API key authentication
  • Metric, imperial, and Kelvin unit systems
  • Localized descriptions in more than 40 languages
Send your first request →Open API playground
Bash · curlGET /data/2.5/weather
