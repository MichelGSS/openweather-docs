5-day forecast endpoint

Returns 3-hour weather forecast intervals across 5 days (up to 40 intervals) for a geographic coordinate pair (lat and lon).

For daily aggregation and precipitation filtering patterns, see Get a 5-day forecast.

Endpoint​

GET https://api.openweathermap.org/data/2.5/forecast

Query parameters​

ParameterTypeRequiredDefaultDescription
latnumberYes—Latitude in decimal degrees, ranging from -90 to 90 (positive for north, negative for south).
lonnumberYes—Longitude in decimal degrees, ranging from -180 to 180 (positive for east, negative for west).
appidstringYes—32-character hexadecimal API key. See Authentication.
unitsstringNostandardMeasurement system for temperature and wind speed: standard (Kelvin, m/s), metric (Celsius, m/s), or imperial (Fahrenheit, mph). See Unit systems and conversions.
cntnumberNo40Number of chronological 3-hour forecast intervals to return, from 1 to 40 across 5 days (for example, 8 covers 24 hours).
langstringNoenLanguage code for the localized list[].weather[].description value (such as es, fr, de, ja, or pt_br).
modestringNojsonResponse payload format: json or xml.

Legacy location parameters (deprecated)​

Built-in geocoding deprecation

OpenWeatherMap deprecated built-in city-name, city-ID, and postal-code lookups on weather endpoints. Although q, id, and zip remain functional for backward compatibility, resolve place names and postal codes to coordinates first through the Geocoding endpoints and pass lat and lon to this endpoint.

Supply one legacy identifier only when omitting lat and lon:

ParameterTypeRequiredDefaultDescription
qstringConditional—Deprecated. Comma-separated city name, state code (US locations only), and ISO 3166-1 alpha-2 country code formatted as {city},{state},{country} (for example, London,GB or Portland,OR,US). URL-encode spaces and special characters.
idnumberConditional—Deprecated. OpenWeatherMap numeric city identifier (for example, 2643743 for London).
zipstringConditional—Deprecated. Postal or ZIP code and ISO 3166-1 alpha-2 country code formatted as {zip},{country} (for example, 94040,US or EC1A,GB). Defaults to US when the country code is omitted.

Request examples​

  • curl
  • Node.js
  • Python
curl --get "https://api.openweathermap.org/data/2.5/forecast" \
  --data-urlencode "lat=51.5085" \
  --data-urlencode "lon=-0.1257" \
  --data-urlencode "units=metric" \
  --data-urlencode "cnt=8" \
  --data-urlencode "appid=$OPENWEATHER_API_KEY"
const params = new URLSearchParams({
  lat: '51.5085',
  lon: '-0.1257',
  units: 'metric',
  cnt: '8',
  appid: process.env.OPENWEATHER_API_KEY,
});

const response = await fetch(
  `https://api.openweathermap.org/data/2.5/forecast?${params}`,
  { signal: AbortSignal.timeout(10000) }
);

if (!response.ok) {
  throw new Error(`HTTP ${response.status}`);
}

const data = await response.json();
console.log(data);
import os
import requests

response = requests.get(
    "https://api.openweathermap.org/data/2.5/forecast",
    params={
        "lat": 51.5085,
        "lon": -0.1257,
        "units": "metric",
        "cnt": 8,
        "appid": os.environ["OPENWEATHER_API_KEY"],
    },
    timeout=10,
)
response.raise_for_status()
data = response.json()
print(data)

Response fields​

FieldTypeUnitDescription
codstring—Internal status code. Returned as the string "200" on success, unlike the integer 200 returned by the Current weather endpoint.
messagenumber—Internal OpenWeatherMap response parameter (0 on normal responses).
cntnumber—Number of 3-hour forecast intervals returned in list (1–40).
listarray—Chronologically ordered array of 3-hour forecast interval objects.
list[].dtnumberUnix UTC (s)Forecasted interval timestamp in Unix epoch seconds (UTC).
list[].main.tempnumberK, °C, or °FForecasted air temperature (Kelvin for standard, Celsius for metric, Fahrenheit for imperial).
list[].main.feels_likenumberK, °C, or °FHuman-perceived forecasted temperature accounting for wind chill and relative humidity.
list[].main.temp_minnumberK, °C, or °FOptional internal minimum temperature bound at forecast calculation time.
list[].main.temp_maxnumberK, °C, or °FOptional internal maximum temperature bound at forecast calculation time.
list[].main.pressurenumberhPaForecasted atmospheric pressure at sea level by default.
list[].main.sea_levelnumberhPaForecasted atmospheric pressure adjusted to mean sea level.
list[].main.grnd_levelnumberhPaForecasted atmospheric pressure at local ground elevation.
list[].main.humiditynumber%Forecasted relative humidity percentage (0–100).
list[].main.temp_kfnumberK, °C, or °FInternal model calibration parameter.
list[].weatherarray—List of weather condition objects for the interval (list[].weather[0] is primary).
list[].weather[].idnumber—Numeric weather condition code. See OpenWeatherMap weather condition codes.
list[].weather[].mainstring—Weather condition category (Thunderstorm, Drizzle, Rain, Snow, Atmosphere, Clear, or Clouds).
list[].weather[].descriptionstring—Localized condition description within the category, controlled by lang.
list[].weather[].iconstring—Icon identifier (such as 10d or 04n). See OpenWeatherMap weather condition codes.
list[].clouds.allnumber%Forecasted cloudiness percentage (0–100).
list[].wind.speednumberm/s or mphForecasted sustained wind speed (m/s for standard and metric; mph for imperial).
list[].wind.degnumberDegreesForecasted meteorological wind direction (0–360).
list[].wind.gustnumberm/s or mphOptional. Forecasted peak wind gust speed (m/s for standard and metric; mph for imperial).
list[].visibilitynumbermForecasted horizontal visibility in meters, capped at a maximum of 10000 (10 km).
list[].popnumberRatioProbability of precipitation from 0.0 to 1.0 (0.0 equals 0%, 1.0 equals 100%).
list[].rain.3hnumbermmOptional. Forecasted liquid precipitation volume over the preceding 3 hours. Omitted when no rain is forecasted.
list[].snow.3hnumbermmOptional. Forecasted snow liquid-equivalent volume over the preceding 3 hours. Omitted when no snow is forecasted.
list[].sys.podstring—Part of the day at the forecasted timestamp: "d" for day or "n" for night.
list[].dt_txtstringUTCForecasted timestamp formatted as YYYY-MM-DD HH:MM:SS in UTC.
city.idnumber—Deprecated OpenWeatherMap city identifier.
city.namestring—Matched locality name.
city.coord.latnumberDecimal degreesLatitude of the matched location (-90 to 90).
city.coord.lonnumberDecimal degreesLongitude of the matched location (-180 to 180).
city.countrystring—ISO 3166-1 alpha-2 country code (for example, GB or US).
city.populationnumber—Estimated resident population of the matched locality.
city.timezonenumbersOffset in seconds from UTC for the local time zone.
city.sunrisenumberUnix UTC (s)Sunrise time in Unix epoch seconds (UTC).
city.sunsetnumberUnix UTC (s)Sunset time in Unix epoch seconds (UTC).

Status codes​

Status codeMeaningDescription
200OKForecast payload returned (cod is "200").
400Bad RequestMissing location parameters, invalid cnt, or out-of-range coordinates (cod is "400").
401UnauthorizedMissing, invalid, inactive, or unauthorized appid (cod is 401).
404Not FoundLegacy q, id, or zip lookup matched no record (cod is "404").
429Too Many RequestsAccount rate limit exceeded (cod is 429).
5xxServer ErrorUpstream OpenWeatherMap server or gateway error.

For full error payload schemas and cod type behavior, see Error codes.
